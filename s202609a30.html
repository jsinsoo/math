수능·평가원 고난도 미적분 킬러 정복

역함수 적분 & 대칭성 10단계 징검다리 해설

기초 개념부터 복잡한 적분의 상쇄 원리까지 한눈에 파악하기

📌 [문제 조건 및 구하는 값]

실수 전체의 집합에서 미분가능한 함수 $f(x)$가 다음과 같이 정의됩니다:

$$f(x) = 2^{2x + \frac{1}{2}\cos(\pi x)}$$

$f(x)$의 역함수를 $g(x)$라 할 때, 다음 식의 값을 만족하는 서로소인 두 자연수 $p, q$에 대하여 $p+q$를 구하시오.

$$I = \frac{1}{4} \int_{f(1)}^{f(3)} g(x)\,dx + \int_{f(0)}^{f(2)} \frac{2^{4g(x)} g'(x)}{x}\,dx = \frac{q}{p}\sqrt{2}$$
1단계 역함수 적분의 핵심 도구 (치환적분)

역함수 $g(x)$의 양함수 식을 직접 구하는 것은 불가능합니다. 역함수 적분 문제는 항상 원래 함수 $f(t)$의 적분으로 되돌리는 치환적분이 열쇠입니다.

  • $x = f(t) \iff g(x) = t$
  • 양변을 $t$에 대해 미분: $dx = f'(t)\,dt$
  • 적분 구간: $x = f(a) \implies t = a$, $x = f(b) \implies t = b$
2단계 첫 번째 적분식($I_1$) 치환

첫 번째 적분을 $I_1$이라 두고, 1단계의 치환 $x = f(t)$를 적용합니다:

$$I_1 = \int_{f(1)}^{f(3)} g(x)\,dx = \int_{1}^{3} t f'(t)\,dt$$

복잡한 역함수 $g(x)$ 적분이 다항식과 $f'(t)$의 곱 형태로 전환되었습니다.

3단계 $I_1$에 부분적분법 적용

$\int t f'(t)\,dt$ 형태는 미적분의 기본인 부분적분법을 적용합니다:

$$\int_{1}^{3} t f'(t)\,dt = \Big[ t f(t) \Big]_{1}^{3} - \int_{1}^{3} f(t)\,dt = 3f(3) - f(1) - \int_{1}^{3} f(t)\,dt$$

문제에 주어진 계수 $\frac{1}{4}$을 곱해주면 다음과 같이 정리됩니다:

$$\frac{1}{4}I_1 = \frac{3f(3) - f(1)}{4} - \frac{1}{4}\int_{1}^{3} f(t)\,dt$$
4단계 주요 경계값 ($f(0), f(1), f(2), f(3)$) 계산

$f(x) = 2^{2x + \frac{1}{2}\cos(\pi x)}$에 각 정수값을 대입합니다:

  • $f(0) = 2^{0 + \frac{1}{2}\cos(0)} = 2^{1/2} = \sqrt{2}$
  • $f(1) = 2^{2 - \frac{1}{2}} = 2^{3/2} = 2\sqrt{2}$
  • $f(2) = 2^{4 + \frac{1}{2}} = 2^{9/2} = 16\sqrt{2}$
  • $f(3) = 2^{6 - \frac{1}{2}} = 2^{11/2} = 32\sqrt{2}$

이를 3단계의 경계항에 대입하면:

$$\frac{3f(3) - f(1)}{4} = \frac{3(32\sqrt{2}) - 2\sqrt{2}}{4} = \frac{94\sqrt{2}}{4} = \frac{47}{2}\sqrt{2}$$
5단계 두 번째 적분식($I_2$) 치환

두 번째 적분식 $I_2 = \int_{f(0)}^{f(2)} \frac{2^{4g(x)} g'(x)}{x}\,dx$에도 동일하게 $x = f(t)$를 적용합니다.

  • $g(x) = t$
  • $g'(x)\,dx = dt$ (역함수 미분법 성질)
  • $x = f(t)$
  • 적분 구간: $x = f(0) \implies t = 0$, $x = f(2) \implies t = 2$
$$I_2 = \int_{0}^{2} \frac{2^{4t}}{f(t)}\,dt$$
6단계 피적분함수 $\frac{2^{4t}}{f(t)}$의 핵심 대칭성 발견

분모에 $f(t) = 2^{2t + \frac{1}{2}\cos(\pi t)}$를 대입해 지수법칙으로 정리합니다:

$$\frac{2^{4t}}{f(t)} = 2^{4t - (2t + \frac{1}{2}\cos(\pi t))} = 2^{2t - \frac{1}{2}\cos(\pi t)}$$

삼각함수 각변환 공식 $\cos(\pi(t+1)) = -\cos(\pi t)$에 착안하여 $f(t+1)$을 계산해보면:

$$f(t+1) = 2^{2(t+1) + \frac{1}{2}\cos(\pi(t+1))} = 2^{2t + 2 - \frac{1}{2}\cos(\pi t)} = 4 \cdot 2^{2t - \frac{1}{2}\cos(\pi t)}$$

놀랍게도 다음 항등식이 성립합니다:

$$\frac{2^{4t}}{f(t)} = \frac{1}{4} f(t+1)$$
7단계 $I_2$를 $f(t)$ 적분으로 평행이동

6단계 결과를 $I_2$에 대입하고, $u = t+1$로 평행이동 치환을 수행합니다 ($dt = du$):

$$I_2 = \int_{0}^{2} \frac{1}{4} f(t+1)\,dt = \frac{1}{4} \int_{1}^{3} f(u)\,du$$

적분 변수를 $t$로 바꿔 쓰면:

$$I_2 = \frac{1}{4} \int_{1}^{3} f(t)\,dt$$
8단계 두 적분의 완벽한 상쇄 (마법의 순간)

전체 적분식 $I = \frac{1}{4}I_1 + I_2$를 합쳐줍니다:

$$I = \left( \frac{47}{2}\sqrt{2} - \frac{1}{4}\int_{1}^{3} f(t)\,dt \right) + \left( \frac{1}{4}\int_{1}^{3} f(t)\,dt \right)$$

Point 우리가 직접 부정적분을 구할 수 없었던 $\int_{1}^{3} f(t)\,dt$ 항이 부호가 반대이므로 완전히 상쇄됩니다!

$$I = \frac{47}{2}\sqrt{2}$$
9단계 $p, q$ 계수 매칭 및 서로소 확인

문제에서 요구한 형태 $\frac{q}{p}\sqrt{2}$와 비교합니다:

$$\frac{q}{p}\sqrt{2} = \frac{47}{2}\sqrt{2}$$
  • $p = 2$
  • $q = 47$
  • $2$와 $47$은 공약수가 $1$뿐인 서로소인 자연수 조건을 정확히 만족합니다.
10단계 최종 정답 도출

문제에서 구하고자 하는 값 $p + q$를 계산합니다:

$$p + q = 2 + 47 = 49$$

FINAL ANSWER

49

$p = 2$, $q = 47 \implies p + q = 49$
