1. 먼저 이해할 핵심

연속인데 미분불가능하다는 것은 모순이 아닙니다. 연속성은 “끊어지지 않는다”는 조건이고, 미분가능성은 그보다 훨씬 강한 조건으로 “충분히 확대하면 그래프가 직선처럼 보여야 한다”는 국소적 선형성을 요구합니다. 아래 함수들은 확대할 때마다 새로운 진동 또는 새로운 tent가 나타나기 때문에 접선의 기울기가 안정되지 않습니다.
그래프는 증명이 아닙니다. 컴퓨터는 무한합을 그릴 수 없으므로 아래 그림은 N항 부분합입니다. N을 증가시키면 극한함수의 미세 구조가 더 드러나지만, nowhere differentiability의 결론은 정리와 논증에서 나옵니다.

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-1.5, 1.5, 16000)
N = 14
phi = lambda t: np.abs(t - np.round(t))

def W(u):
    a, b = 0.85, 11
    y = np.zeros_like(u)
    for n in range(N):
        y += a**n * np.cos((b**n) * np.pi * u)
    return y

y = W(x)

plt.figure(figsize=(10, 4))
plt.plot(x, y, linewidth=0.8)
plt.title('고전 Weierstrass 함수')
plt.xlabel("x")
plt.ylabel("f(x)")
plt.grid(alpha=0.25)
plt.tight_layout()
plt.show()

φ(t)=dist(t,ℤ)는 정수 사이에서 삼각형 모양을 이루는 tent 함수입니다. 더 작고 더 촘촘한 tent가 모든 단계에서 겹쳐집니다.

왜 연속인가?

각 급수항은 연속이고, 사용한 계수는 항의 최대 크기를 기하급수적으로 감소시킵니다. 따라서 관련 급수는 균등수렴하며 극한함수는 연속입니다. 변환형에서는 연속함수의 합성·합 역시 연속입니다.

왜 모든 점에서 미분불가능한가?

각 항의 크기는 2⁻ⁿ/2 이하라서 Weierstrass M-test로 균등수렴하고 따라서 연속입니다. Takagi 함수는 어느 점에서도 유한한 미분계수를 갖지 않는 고전적 예입니다.

그래프에서 관찰할 점

Takagi 그래프를 5배 압축하고 상하 반전한 뒤 부드러운 코사인파를 더했습니다. 시각적으로는 원형과 꽤 달라 보입니다.

왜 연속인가?

각 급수항은 연속이고, 사용한 계수는 항의 최대 크기를 기하급수적으로 감소시킵니다. 따라서 관련 급수는 균등수렴하며 극한함수는 연속입니다. 변환형에서는 연속함수의 합성·합 역시 연속입니다.

왜 모든 점에서 미분불가능한가?

T(5x+0.2)는 nowhere differentiable이고 −1.3배 역시 성질을 유지합니다. 여기에 C∞ 코사인함수를 더해도 어느 점에서도 유한한 미분계수는 생기지 않습니다.

Python 예시코드 보기
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-1.5, 1.5, 16000)
N = 14
phi = lambda t: np.abs(t - np.round(t))

def F(u, r=2):
    y = np.zeros_like(u)
    for n in range(N):
        y += r**(-n) * phi((r**n)*u)
    return y

y = -1.3*F(5*x + (0.2)) + (0.15*np.cos(2*np.pi*x))

plt.figure(figsize=(10, 4))
plt.plot(x, y, linewidth=0.8)
plt.title('다중변환 Takagi 함수')
plt.xlabel("x")
plt.ylabel("f(x)")
plt.grid(alpha=0.25)
plt.tight_layout()
plt.show()

4. 왜 변형해도 성질이 유지될까?

① affine 입력변환

F(x)=f(ax+b), a≠0이라 하겠습니다. F가 x₀에서 미분가능하다면 변수 u=ax+b를 이용한 차분몫으로부터 f가 u₀=ax₀+b에서 미분가능해집니다. 따라서 f가 nowhere differentiable이면 F도 nowhere differentiable입니다.

② 미분가능한 함수 더하기

f가 nowhere differentiable이고 g가 모든 점에서 미분가능하다고 합시다. f+g가 x₀에서 미분가능하면 f=(f+g)−g도 x₀에서 미분가능해야 하므로 모순입니다. 따라서 f+g 역시 nowhere differentiable입니다.

③ 0이 아닌 상수배

c≠0일 때 cf가 미분가능하면 f=(1/c)(cf)도 미분가능합니다. 그러므로 상하 확대·축소·반전은 성질을 바꾸지 않습니다.

④ 균등수렴과 연속성

φ(t)=dist(t,ℤ)는 0≤φ≤1/2입니다. 따라서 Σr⁻ⁿφ(rⁿx)의 n번째 항은 모든 x에서 1/(2rⁿ) 이하이고, 이 상계급수는 수렴합니다. M-test에 의해 균등수렴하며 연속함수들의 균등극한이므로 연속입니다.

6. 참고 및 수학적 주의

“모든 점에서 미분불가능”은 여기서 유한한 보통 미분계수가 어느 점에서도 존재하지 않는다는 표준 의미로 사용했습니다. Takagi 함수는 일부 점에서 ±∞ 형태의 부정형/무한 도함수를 가질 수 있으므로, Knopp의 더 강한 예와 구별할 필요가 있습니다.
