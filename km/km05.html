정적분을 과학과 공학의 언어로 읽기

정적분은 단순히 ‘넓이를 구하는 계산’이 아니라 순간적인 양을 연속적으로 합하여 전체량을 구하는 도구입니다. 속도→변위, 힘→일, 전류→전하, 반응속도→반응량, 유량→체적, 농도→노출량, 밀도→질량, 광도→복사에너지처럼 서로 다른 분야가 같은 수학적 구조로 연결됩니다.

\[\boxed{\text{전체량}=\int_a^b \text{밀도·속도·율·세기}\,d(\text{변수})}\]

학습 방법: 각 문제에서 먼저 적분의 물리적 의미와 단위를 확인하고, 적분식을 세운 다음 치환·부분적분·대칭성·무한적분·감마/가우스형 적분 등 필요한 기법을 선택하도록 구성했습니다.

Ⅰ. 물리학 20문제

1변가속도 운동의 변위

문제
\[v(t)=3t^2-2t+1\ (\mathrm{m/s}).\ 0\le t\le2\text{에서 변위를 구하여라.}\]
적용 개념

속도를 시간에 대해 정적분하면 변위가 된다.

단계별 상세 풀이
  1. \[\Delta x=\int_0^2v(t)\,dt\]
  2. \[=\left[t^3-t^2+t\right]_0^2\]
  3. \[=8-4+2=6\ \mathrm m\]
최종 답\(6\ \mathrm m\)

2속력과 이동거리

문제
\[v(t)=t-2,\ 0\le t\le5.\text{ 총 이동거리를 구하여라.}\]
적용 개념

이동거리는 속도의 절댓값을 적분한다.

단계별 상세 풀이
  1. \[v(t)=0\Rightarrow t=2\text{에서 방향이 바뀐다.}\]
  2. \[D=-\int_0^2(t-2)dt+\int_2^5(t-2)dt\]
  3. \[=2+\frac92=\frac{13}{2}\ \mathrm m\]
최종 답\(\frac{13}{2}\ \mathrm m\)

3가속도에서 속도

문제
\[a(t)=6t-4,\quad v(0)=3.\quad v(3)\text{을 구하여라.}\]
적용 개념

가속도의 적분은 속도 변화량이다.

단계별 상세 풀이
  1. \[v(3)-v(0)=\int_0^3(6t-4)dt\]
  2. \[=[3t^2-4t]_0^3=27-12=15\]
  3. \[v(3)=3+15=18\]
최종 답\(18\ \mathrm{m/s}\)

4힘이 한 일

문제
\[F(x)=4x^3\ (\mathrm N).\ 0\le x\le2\text{에서 한 일을 구하여라.}\]
적용 개념

위치에 따라 변하는 힘이 한 일은 F(x)의 위치 적분이다.

단계별 상세 풀이
  1. \[W=\int_0^2F(x)dx\]
  2. \[=\int_0^24x^3dx=[x^4]_0^2\]
  3. \[=16\ \mathrm J\]
최종 답\(16\ \mathrm J\)

문제

단계별 상세 풀이

  2. \[=[100x^2]_0^{0.1}\]

최종 답\(1\ \mathrm J\)

7선밀도와 질량

8질량중심

문제
\[\lambda(x)=x,\ 0\le x\le2.\text{ 막대의 질량중심 }\bar x\text{를 구하여라.}\]
적용 개념

질량중심은 1차 모멘트를 총질량으로 나눈 값이다.

단계별 상세 풀이
  1. \[M=\int_0^2x\,dx=2\]
  2. \[\bar x=\frac1M\int_0^2x\lambda(x)dx=\frac12\int_0^2x^2dx\]
  3. \[=\frac12\cdot\frac83=\frac43\]
최종 답\(\frac43\ \mathrm m\)

20상대론적 모형 적분

문제

적용 개념

단계별 상세 풀이

최종 답\(\frac{\beta}{\sqrt{1-\beta^2}}\)
