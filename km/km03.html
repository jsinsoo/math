한 줄에 한 문제씩 · 기초 → 지수·로그 → 삼각함수 → 대칭 → 치환 → 부분적분 → 넓이 → 미적분 기본정리

정적분 풀이의 출발점

원시함수 \(F(x)\)를 구한 뒤 상한의 값에서 하한의 값을 뺍니다.

\[\int_a^b f(x)\,dx=F(b)-F(a),\qquad F'(x)=f(x)\]

학습 순서: 피적분함수 구조 확인 → 원시함수 또는 적분 방법 결정 → 상·하한 대입 → 계산 → 넓이 문제라면 부호 변화 확인 순으로 풀이합니다.

Ⅰ. 거듭제곱함수 · 기본 정적분

1기본 1

문제
\[\int_{0}^{1}x^{1}\,dx\]
풀이 핵심

거듭제곱은 지수를 1 올리고 새 지수로 나눈 뒤, 상한값에서 하한값을 뺍니다.

상세 풀이
  1. \[\int x^{1}dx=\frac{x^{2}}{2}\]
  2. \[\int_{0}^{1}x^{1}dx=\left[\frac{x^{2}}{2}\right]_{0}^{1}\]
  3. \[=\frac{1^{2}-0^{2}}{2}=\frac{1}{2}\]
정답\(\frac{1}{2}\)

\[\int_0^1x^2e^xdx\]
풀이 핵심

곱의 형태에서 미분하면 단순해지는 항을 u로 선택하고 ∫u dv=uv-∫v du를 적용합니다.

상세 풀이
  1. \[\int x^2e^xdx=e^x(x^2-2x+2)\]
  2. \[[e^x(x^2-2x+2)]_0^1=e-2\]
정답\(e-2\)
