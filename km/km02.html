적분을 공부하는 핵심 방법

적분은 크게 미분의 역과정인 부정적분과 구간에서의 누적량을 구하는 정적분으로 나뉩니다. 공식을 외울 때에는 결과만 기억하기보다 결과를 다시 미분하여 원래 피적분함수가 되는지 확인하는 습관이 중요합니다.

\[\int f(x)\,dx=F(x)+C\quad\Longleftrightarrow\quad F'(x)=f(x)\]
학습 팁: ① 거듭제곱인지 확인 → ② 분모의 미분이 분자에 있는지 확인 → ③ 합성함수형이면 치환을 생각 → ④ 곱이면 부분적분을 검토 → ⑤ 이차식·삼각식은 표준형과 항등식을 확인하세요.

Ⅰ. 기본 부정적분 공식

1적분의 기본형

\[\int f(x)\,dx=F(x)+C\quad(F'(x)=f(x))\]
상세 설명

부정적분은 미분하면 원래 함수가 되는 모든 원시함수를 찾는 과정이다. 서로 다른 원시함수는 상수만큼 차이가 나므로 적분상수 C를 반드시 붙인다.

예시
\[\int 2x\,dx=x^2+C\]

2상수의 적분

\[\int k\,dx=kx+C\]
상세 설명

상수 k를 적분하면 x에 대한 일차식 kx가 된다. 실제로 kx를 미분하면 k가 된다.

예시
\[\int 5\,dx=5x+C\]

3거듭제곱 공식

\[\int x^n\,dx=\frac{x^{n+1}}{n+1}+C\quad(n\ne-1)\]
상세 설명

지수를 1 증가시키고 새 지수로 나눈다. n=-1일 때는 분모가 0이 되므로 로그 공식을 별도로 사용한다.

예시
\[\int x^4\,dx=\frac{x^5}{5}+C\]

4상수배 법칙

\[\int kf(x)\,dx=k\int f(x)\,dx\]
상세 설명

적분식에 곱해진 상수는 적분 기호 밖으로 꺼낼 수 있다. 계산을 단순하게 만드는 기본 선형성이다.

예시
\[\int 3x^2\,dx=3\cdot\frac{x^3}{3}=x^3+C\]

5합의 적분

\[\int(f+g)\,dx=\int f\,dx+\int g\,dx\]
상세 설명

여러 항의 합은 각 항을 따로 적분한 뒤 더할 수 있다.

예시
\[\int(x^2+x)\,dx=\frac{x^3}{3}+\frac{x^2}{2}+C\]

6차의 적분

\[\int(f-g)\,dx=\int f\,dx-\int g\,dx\]
상세 설명

뺄셈도 적분의 선형성에 따라 항별로 처리한다.

예시
\[\int(x^3-x)\,dx=\frac{x^4}{4}-\frac{x^2}{2}+C\]

71/x 적분

\[\int\frac1x\,dx=\ln|x|+C\]
상세 설명

거듭제곱 공식에서 제외된 n=-1의 특별한 경우이다. x가 음수일 수도 있으므로 절댓값을 사용한다.

예시
\[\int\frac{3}{x}\,dx=3\ln|x|+C\]

8음의 거듭제곱

\[\int x^{-n}\,dx=\frac{x^{-n+1}}{-n+1}+C\quad(n\ne1)\]
상세 설명

분수식을 음의 지수로 바꾸면 거듭제곱 공식으로 쉽게 적분할 수 있다.

예시
\[\int\frac1{x^3}\,dx=-\frac1{2x^2}+C\]

9제곱근 적분

\[\int\sqrt{x}\,dx=\frac23x^{3/2}+C\]
상세 설명

제곱근을 x^(1/2)로 바꾼 뒤 거듭제곱 공식을 적용한다.

예시
\[\int\sqrt{x}\,dx=\frac23x\sqrt{x}+C\]

10세제곱근 적분

\[\int\sqrt[3]{x}\,dx=\frac34x^{4/3}+C\]
상세 설명

세제곱근은 x^(1/3)로 바꾸고 지수를 1 증가시켜 나눈다.

예시
\[\int\sqrt[3]{x}\,dx=\frac34x^{4/3}+C\]

111/√x 적분

\[\int\frac1{\sqrt{x}}\,dx=2\sqrt{x}+C\]
상세 설명

1/√x=x^(-1/2)이므로 거듭제곱 공식을 적용하면 된다.

예시
\[\int\frac{4}{\sqrt{x}}\,dx=8\sqrt{x}+C\]

12일차식의 거듭제곱

\[\int(ax+b)^n\,dx=\frac{(ax+b)^{n+1}}{a(n+1)}+C\]
상세 설명

안쪽 ax+b의 미분이 a이므로 그만큼 나누어 보정한다. 치환적분의 가장 기본적인 형태이다.

예시
\[\int(2x+1)^3dx=\frac{(2x+1)^4}{8}+C\]

13일차식의 역수

\[\int\frac{dx}{ax+b}=\frac1a\ln|ax+b|+C\]
상세 설명

u=ax+b로 치환하면 du=a dx이므로 1/a가 앞에 붙는다.

예시
\[\int\frac{dx}{3x+2}=\frac13\ln|3x+2|+C\]

14다항식 적분

\[\int\sum a_kx^kdx=\sum a_k\frac{x^{k+1}}{k+1}+C\]
상세 설명

다항식은 항별로 거듭제곱 공식을 적용한다.

예시
\[\int(3x^2-4x+2)dx=x^3-2x^2+2x+C\]

15상수 구간 정적분

\[\int_a^b k\,dx=k(b-a)\]
상세 설명

높이가 k인 직사각형의 부호 있는 넓이와 같다.

예시
\[\int_1^4 3\,dx=9\]

Ⅱ. 지수·로그 함수 적분

16자연지수

\[\int e^x dx=e^x+C\]
상세 설명

e^x는 미분해도 자기 자신이므로 적분해도 같은 형태가 유지된다.

예시
\[\int e^x dx=e^x+C\]

17합성 자연지수

\[\int e^{ax+b}dx=\frac1a e^{ax+b}+C\]
상세 설명

지수 ax+b의 미분 a를 보정하기 위해 1/a를 곱한다.

예시
\[\int e^{2x+1}dx=\frac12e^{2x+1}+C\]

18일반 지수

\[\int a^x dx=\frac{a^x}{\ln a}+C\]
상세 설명

a^x의 미분이 a^x ln a이므로 ln a로 나눈다.

예시
\[\int2^x dx=\frac{2^x}{\ln2}+C\]

19합성 일반 지수

\[\int a^{mx+b}dx=\frac{a^{mx+b}}{m\ln a}+C\]
상세 설명

지수의 미분 m과 밑에서 생기는 ln a를 함께 보정한다.

예시
\[\int3^{2x}dx=\frac{3^{2x}}{2\ln3}+C\]

20로그

\[\int\ln x\,dx=x\ln x-x+C\]
상세 설명

부분적분에서 u=ln x, dv=dx로 두면 얻어진다.

예시
\[\int\ln x\,dx=x\ln x-x+C\]

21log_a x

\[\int\log_a x\,dx=\frac{x\ln x-x}{\ln a}+C\]
상세 설명

밑변환 log_a x=ln x/ln a를 이용한다.

예시
\[\int\log_2x\,dx=\frac{x\ln x-x}{\ln2}+C\]

22x e^{x²}

\[\int xe^{x^2}dx=\frac12e^{x^2}+C\]
상세 설명

u=x²로 두면 du=2x dx가 되어 즉시 적분된다.

예시
\[\int2xe^{x^2}dx=e^{x^2}+C\]

23f'/f 형태

\[\int\frac{f'(x)}{f(x)}dx=\ln|f(x)|+C\]
상세 설명

분모 함수의 미분이 분자에 나타나면 로그 적분을 의심한다.

예시
\[\int\frac{2x}{x^2+1}dx=\ln(x^2+1)+C\]

24e^x/(1+e^x)

\[\int\frac{e^x}{1+e^x}dx=\ln(1+e^x)+C\]
상세 설명

분모 1+e^x의 미분이 분자 e^x와 정확히 같다.

예시
\[\int\frac{e^x}{1+e^x}dx=\ln(1+e^x)+C\]

25ln(ax+b)

\[\int\ln(ax+b)dx=\frac{(ax+b)\ln|ax+b|-(ax+b)}a+C\]
상세 설명

u=ax+b로 치환한 뒤 ∫ln u du 공식을 사용한다.

예시
\[\int\ln(2x+1)dx=\frac{(2x+1)\ln|2x+1|-(2x+1)}2+C\]

26x ln x

\[\int x\ln x\,dx=\frac{x^2}{2}\ln x-\frac{x^2}{4}+C\]
상세 설명

부분적분에서 u=ln x, dv=x dx로 두는 대표 예이다.

예시
\[\int x\ln x\,dx=\frac{x^2}{2}\ln x-\frac{x^2}{4}+C\]

27ln²x

\[\int(\ln x)^2dx=x[(\ln x)^2-2\ln x+2]+C\]
상세 설명

부분적분을 반복하면 로그의 차수가 한 단계씩 낮아진다.

예시
\[\int(\ln x)^2dx=x[(\ln x)^2-2\ln x+2]+C\]

28x^n ln x

\[\int x^n\ln x\,dx=\frac{x^{n+1}}{n+1}\ln x-\frac{x^{n+1}}{(n+1)^2}+C\]
상세 설명

부분적분을 사용하면 거듭제곱 적분과 로그 적분이 결합된다.

예시
\[\int x^2\ln x\,dx=\frac{x^3}{3}\ln x-\frac{x^3}{9}+C\]

Ⅲ. 삼각함수 적분

29sin

\[\int\sin xdx=-\cos x+C\]
상세 설명

cos x의 미분이 -sin x이므로 음수를 붙인다.

예시
\[\int\sin xdx=-\cos x+C\]

30cos

\[\int\cos xdx=\sin x+C\]
상세 설명

sin x의 미분이 cos x이다.

예시
\[\int3\cos xdx=3\sin x+C\]

31sec²

\[\int\sec^2x dx=\tan x+C\]
상세 설명

tan x의 도함수가 sec²x이다.

예시
\[\int2\sec^2x dx=2\tan x+C\]

32csc²

\[\int\csc^2x dx=-\cot x+C\]
상세 설명

cot x의 도함수가 -csc²x임을 이용한다.

예시
\[\int\csc^2x dx=-\cot x+C\]

33sec·tan

\[\int\sec x\tan xdx=\sec x+C\]
상세 설명

sec x의 미분 공식의 역과정이다.

예시
\[\int4\sec x\tan xdx=4\sec x+C\]

34csc·cot

\[\int\csc x\cot xdx=-\csc x+C\]
상세 설명

csc x의 도함수가 -csc x cot x이다.

예시
\[\int\csc x\cot xdx=-\csc x+C\]

35tan

\[\int\tan xdx=-\ln|\cos x|+C\]
상세 설명

tan=sin/cos로 쓰고 u=cos x로 치환한다.

예시
\[\int\tan xdx=\ln|\sec x|+C\]

36cot

\[\int\cot xdx=\ln|\sin x|+C\]
상세 설명

cot=cos/sin으로 쓰면 분모 sin x의 미분이 분자에 나타난다.

예시
\[\int\cot xdx=\ln|\sin x|+C\]

37sec

\[\int\sec xdx=\ln|\sec x+\tan x|+C\]
상세 설명

분자·분모에 sec x+tan x를 활용하여 로그 미분형으로 변형한다.

예시
\[\int\sec xdx=\ln|\sec x+\tan x|+C\]

38csc

\[\int\csc xdx=\ln|\csc x-\cot x|+C\]
상세 설명

적절한 항을 곱해 로그 미분형으로 만든 결과이다.

예시
\[\int\csc xdx=\ln|\csc x-\cot x|+C\]

39sin(ax)

\[\int\sin(ax)dx=-\frac1a\cos(ax)+C\]
상세 설명

안쪽 ax의 미분 a를 1/a로 보정한다.

예시
\[\int\sin3x dx=-\frac13\cos3x+C\]

40cos(ax)

\[\int\cos(ax)dx=\frac1a\sin(ax)+C\]
상세 설명

연쇄법칙의 역과정으로 1/a가 붙는다.

예시
\[\int\cos2x dx=\frac12\sin2x+C\]

41sin²

\[\int\sin^2x dx=\frac x2-\frac{\sin2x}{4}+C\]
상세 설명

반각공식 sin²x=(1-cos2x)/2를 사용한다.

예시
\[\int\sin^2x dx=\frac x2-\frac{\sin2x}{4}+C\]

42cos²

\[\int\cos^2x dx=\frac x2+\frac{\sin2x}{4}+C\]
상세 설명

반각공식 cos²x=(1+cos2x)/2를 사용한다.

예시
\[\int\cos^2x dx=\frac x2+\frac{\sin2x}{4}+C\]

43tan²

\[\int\tan^2x dx=\tan x-x+C\]
상세 설명

tan²x=sec²x-1로 바꾼다.

예시
\[\int\tan^2x dx=\tan x-x+C\]

44cot²

\[\int\cot^2x dx=-\cot x-x+C\]
상세 설명

cot²x=csc²x-1을 사용한다.

예시
\[\int\cot^2x dx=-\cot x-x+C\]

45sin x cos x

\[\int\sin x\cos xdx=\frac12\sin^2x+C\]
상세 설명

u=sin x로 두면 du=cos x dx이다.

예시
\[\int2\sin x\cos xdx=\sin^2x+C\]

46sin(mx)cos(mx)

\[\int\sin(mx)\cos(mx)dx=\frac{\sin^2(mx)}{2m}+C\]
상세 설명

u=sin(mx)로 치환하면 du=m cos(mx)dx이다.

예시
\[\int\sin2x\cos2x dx=\frac14\sin^2 2x+C\]

Ⅳ. 역삼각함수로 나타나는 적분

471/(1+x²)

\[\int\frac{dx}{1+x^2}=\arctan x+C\]
상세 설명

arctan x의 미분을 거꾸로 이용한다.

예시
\[\int\frac{dx}{1+x^2}=\arctan x+C\]

481/(a²+x²)

\[\int\frac{dx}{a^2+x^2}=\frac1a\arctan\frac xa+C\quad(a>0)\]
상세 설명

x/a로 크기를 표준형 1/(1+u²)에 맞춘다.

예시
\[\int\frac{dx}{4+x^2}=\frac12\arctan\frac x2+C\]

491/√(1-x²)

\[\int\frac{dx}{\sqrt{1-x^2}}=\arcsin x+C\]
상세 설명

arcsin x의 도함수와 정확히 일치한다.

예시
\[\int\frac{dx}{\sqrt{1-x^2}}=\arcsin x+C\]

501/√(a²-x²)

\[\int\frac{dx}{\sqrt{a^2-x^2}}=\arcsin\frac xa+C\quad(a>0)\]
상세 설명

x=a u로 치환하면 표준 arcsin 형태가 된다.

예시
\[\int\frac{dx}{\sqrt{9-x^2}}=\arcsin\frac x3+C\]

511/(x²-a²)

\[\int\frac{dx}{x^2-a^2}=\frac1{2a}\ln\left|\frac{x-a}{x+a}\right|+C\]
상세 설명

부분분수로 1/(x-a), 1/(x+a)의 차로 분해한다.

예시
\[\int\frac{dx}{x^2-1}=\frac12\ln\left|\frac{x-1}{x+1}\right|+C\]

521/(a²-x²)

\[\int\frac{dx}{a^2-x^2}=\frac1{2a}\ln\left|\frac{a+x}{a-x}\right|+C\]
상세 설명

인수분해 후 부분분수를 적용한다.

예시
\[\int\frac{dx}{4-x^2}=\frac14\ln\left|\frac{2+x}{2-x}\right|+C\]

531/√(x²+a²)

\[\int\frac{dx}{\sqrt{x^2+a^2}}=\ln|x+\sqrt{x^2+a^2}|+C\]
상세 설명

쌍곡치환 또는 표준 로그형으로 얻어진다.

예시
\[\int\frac{dx}{\sqrt{x^2+4}}=\ln|x+\sqrt{x^2+4}|+C\]

541/√(x²-a²)

\[\int\frac{dx}{\sqrt{x^2-a^2}}=\ln|x+\sqrt{x^2-a^2}|+C\]
상세 설명

x=a sec θ 같은 삼각치환으로 유도할 수 있다.

예시
\[\int\frac{dx}{\sqrt{x^2-9}}=\ln|x+\sqrt{x^2-9}|+C\]

551/(x√(x²-a²))

\[\int\frac{dx}{x\sqrt{x^2-a^2}}=\frac1a\operatorname{arcsec}\left|\frac xa\right|+C\]
상세 설명

x=a sec θ로 치환하면 sec·tan 구조가 소거된다.

예시
\[\int\frac{dx}{x\sqrt{x^2-4}}=\frac12\operatorname{arcsec}\left|\frac x2\right|+C\]

561/(1-x²)

\[\int\frac{dx}{1-x^2}=\operatorname{artanh}x+C\]
상세 설명

|x|<1에서는 역쌍곡탄젠트로 간결하게 표현할 수 있다.

예시
\[\int\frac{dx}{1-x^2}=\frac12\ln\left|\frac{1+x}{1-x}\right|+C\]

57f'/(1+f²)

\[\int\frac{f'(x)}{1+f(x)^2}dx=\arctan(f(x))+C\]
상세 설명

arctan 합성함수의 미분을 거꾸로 적용한다.

예시
\[\int\frac{2x}{1+x^4}dx=\arctan(x^2)+C\]

58f'/√(1-f²)

\[\int\frac{f'(x)}{\sqrt{1-f(x)^2}}dx=\arcsin(f(x))+C\]
상세 설명

arcsin 합성함수의 미분형이다.

예시
\[\int\frac{2x}{\sqrt{1-x^4}}dx=\arcsin(x^2)+C\]

63sech·tanh

\[\int\operatorname{sech}x\tanh xdx=-\operatorname{sech}x+C\]
상세 설명

sech의 미분에 음수가 포함된다.

예시
\[\int\operatorname{sech}x\tanh xdx=-\operatorname{sech}x+C\]

64csch·coth

\[\int\operatorname{csch}x\coth xdx=-\operatorname{csch}x+C\]
상세 설명

csch의 도함수를 거꾸로 이용한다.

예시
\[\int\operatorname{csch}x\coth xdx=-\operatorname{csch}x+C\]

65tanh

\[\int\tanh xdx=\ln(\cosh x)+C\]
상세 설명

tanh=sinh/cosh이고 분모 cosh의 미분이 sinh이다.

예시
\[\int\tanh xdx=\ln(\cosh x)+C\]

66coth

\[\int\coth xdx=\ln|\sinh x|+C\]
상세 설명

coth=cosh/sinh이므로 로그 미분형이다.

예시
\[\int\coth xdx=\ln|\sinh x|+C\]

67sech

\[\int\operatorname{sech}x dx=\arctan(\sinh x)+C\]
상세 설명

arctan(sinh x)을 미분하면 cosh/(1+sinh²)=sech가 된다.

예시
\[\int\operatorname{sech}x dx=\arctan(\sinh x)+C\]

68sinh(ax)

\[\int\sinh(ax)dx=\frac1a\cosh(ax)+C\]
상세 설명

안쪽 ax의 미분 a를 보정한다.

예시
\[\int\sinh2x dx=\frac12\cosh2x+C\]

69cosh(ax)

\[\int\cosh(ax)dx=\frac1a\sinh(ax)+C\]
상세 설명

합성함수 미분의 역과정이다.

예시
\[\int\cosh3x dx=\frac13\sinh3x+C\]

70tanh(ax)

\[\int\tanh(ax)dx=\frac1a\ln(\cosh(ax))+C\]
상세 설명

u=ax 치환 또는 로그 미분형을 이용한다.

예시
\[\int\tanh2x dx=\frac12\ln(\cosh2x)+C\]

Ⅵ. 치환적분·부분적분 대표 공식

71치환적분

\[\int f(g(x))g'(x)dx=\int f(u)du,\quad u=g(x)\]
상세 설명

복잡한 안쪽 함수를 하나의 새 변수 u로 바꾸어 단순한 적분으로 환원한다.

예시
\[\int2x(x^2+1)^5dx=\frac{(x^2+1)^6}{6}+C\]

72부분적분

\[\int u\,dv=uv-\int v\,du\]
상세 설명

곱의 미분법을 적분 형태로 바꾼 공식이다. 다항식×지수·삼각·로그에서 특히 유용하다.

예시
\[\int xe^x dx=xe^x-e^x+C\]

73x e^{ax}

\[\int xe^{ax}dx=e^{ax}\left(\frac xa-\frac1{a^2}\right)+C\]
상세 설명

부분적분에서 u=x, dv=e^{ax}dx로 둔다.

예시
\[\int xe^{2x}dx=e^{2x}(x/2-1/4)+C\]

74x sin x

\[\int x\sin xdx=-x\cos x+\sin x+C\]
상세 설명

u=x, dv=sin x dx로 부분적분한다.

예시
\[\int x\sin xdx=-x\cos x+\sin x+C\]

75x cos x

\[\int x\cos xdx=x\sin x+\cos x+C\]
상세 설명

u=x, dv=cos x dx로 두면 된다.

예시
\[\int x\cos xdx=x\sin x+\cos x+C\]

76x²e^x

\[\int x^2e^xdx=e^x(x^2-2x+2)+C\]
상세 설명

부분적분을 두 번 반복한다.

예시
\[\int x^2e^xdx=e^x(x^2-2x+2)+C\]

77e^{ax}sin bx

\[\int e^{ax}\sin bx\,dx=\frac{e^{ax}(a\sin bx-b\cos bx)}{a^2+b^2}+C\]
상세 설명

부분적분을 두 번 적용하면 원래 적분이 다시 나타나므로 이를 대수적으로 풀어 얻는다.

예시
\[\int e^x\sin xdx=\frac{e^x}{2}(\sin x-\cos x)+C\]

78e^{ax}cos bx

\[\int e^{ax}\cos bx\,dx=\frac{e^{ax}(a\cos bx+b\sin bx)}{a^2+b^2}+C\]
상세 설명

지수함수와 삼각함수의 곱에 대한 표준 결과이다.

예시
\[\int e^x\cos xdx=\frac{e^x}{2}(\cos x+\sin x)+C\]

79f'f^n

\[\int f'(x)f(x)^n dx=\frac{f(x)^{n+1}}{n+1}+C\]
상세 설명

u=f(x) 치환의 직접적인 패턴이다.

예시
\[\int2x(x^2+3)^4dx=\frac{(x^2+3)^5}{5}+C\]

80f'e^f

\[\int f'(x)e^{f(x)}dx=e^{f(x)}+C\]
상세 설명

e^u의 적분과 u=f(x) 치환을 결합한다.

예시
\[\int2xe^{x^2}dx=e^{x^2}+C\]

81f'cos f

\[\int f'(x)\cos(f(x))dx=\sin(f(x))+C\]
상세 설명

sin(f(x))의 미분을 거꾸로 읽은 형태이다.

예시
\[\int2x\cos(x^2)dx=\sin(x^2)+C\]

82f'sin f

\[\int f'(x)\sin(f(x))dx=-\cos(f(x))+C\]
상세 설명

cos 합성함수의 미분을 역으로 이용한다.

예시
\[\int2x\sin(x^2)dx=-\cos(x^2)+C\]

Ⅶ. 유리함수·부분분수 적분

831/[x(x+a)]

\[\int\frac{dx}{x(x+a)}=\frac1a\ln\left|\frac{x}{x+a}\right|+C\]
상세 설명

1/[x(x+a)]를 두 개의 단순 분수로 분해한다.

예시
\[\int\frac{dx}{x(x+2)}=\frac12\ln\left|\frac{x}{x+2}\right|+C\]

841/[(x-a)(x-b)]

\[\int\frac{dx}{(x-a)(x-b)}=\frac1{a-b}\ln\left|\frac{x-a}{x-b}\right|+C\]
상세 설명

서로 다른 일차인수가 있을 때 부분분수 분해를 사용한다.

예시
\[\int\frac{dx}{(x-1)(x-3)}=-\frac12\ln\left|\frac{x-1}{x-3}\right|+C\]

85x/(x²+a²)

\[\int\frac{x}{x^2+a^2}dx=\frac12\ln(x^2+a^2)+C\]
상세 설명

분모의 미분 2x가 분자 x와 상수배 관계이다.

예시
\[\int\frac{x}{x^2+4}dx=\frac12\ln(x^2+4)+C\]

86x/(a²-x²)

\[\int\frac{x}{a^2-x^2}dx=-\frac12\ln|a^2-x^2|+C\]
상세 설명

u=a²-x²로 두면 du=-2x dx이다.

예시
\[\int\frac{x}{9-x^2}dx=-\frac12\ln|9-x^2|+C\]

87(2x+b)/(x²+bx+c)

\[\int\frac{2x+b}{x^2+bx+c}dx=\ln|x^2+bx+c|+C\]
상세 설명

분자가 분모의 도함수와 정확히 일치하는 로그형이다.

예시
\[\int\frac{2x+3}{x^2+3x+5}dx=\ln(x^2+3x+5)+C\]

881/(x+a)²

\[\int\frac{dx}{(x+a)^2}=-\frac1{x+a}+C\]
상세 설명

(x+a)^(-2)에 거듭제곱 적분을 적용한다.

예시
\[\int\frac{dx}{(x+2)^2}=-\frac1{x+2}+C\]

891/(ax+b)²

\[\int\frac{dx}{(ax+b)^2}=-\frac1{a(ax+b)}+C\]
상세 설명

u=ax+b 치환으로 1/a가 추가된다.

예시
\[\int\frac{dx}{(2x+1)^2}=-\frac1{2(2x+1)}+C\]

90x²/(x²+a²)

\[\int\frac{x^2}{x^2+a^2}dx=x-a\arctan(x/a)+C\]
상세 설명

x²=(x²+a²)-a²로 분자를 분리한다.

예시
\[\int\frac{x^2}{x^2+4}dx=x-2\arctan(x/2)+C\]

911/(x²+2ax+a²)

\[\int\frac{dx}{(x+a)^2}=-\frac1{x+a}+C\]
상세 설명

완전제곱식임을 알아보면 단순 거듭제곱 적분이 된다.

예시
\[\int\frac{dx}{x^2+4x+4}=-\frac1{x+2}+C\]

92(ax+b)/(cx+d)

\[\int\frac{ax+b}{cx+d}dx=\frac acx+\frac{bc-ad}{c^2}\ln|cx+d|+C\]
상세 설명

분자를 분모의 상수배와 나머지로 나누어 다항항과 로그항으로 분리한다.

예시
\[\int\frac{2x+1}{x+1}dx=2x-\ln|x+1|+C\]

Ⅷ. 정적분·대칭·미적분 기본정리

93미적분 기본정리

\[\int_a^b f(x)dx=F(b)-F(a)\quad(F'=f)\]
상세 설명

정적분은 원시함수의 양 끝값 차로 계산한다. 넓이와 미분을 연결하는 핵심 정리이다.

예시
\[\int_0^2x^2dx=\left[\frac{x^3}{3}\right]_0^2=\frac83\]

94정적분의 구간 분할

\[\int_a^b fdx+\int_b^c fdx=\int_a^c fdx\]
상세 설명

인접한 구간의 부호 있는 넓이는 합칠 수 있다.

예시
\[\int_0^1x dx+\int_1^2x dx=\int_0^2x dx=2\]

95상하한 교환

\[\int_a^b fdx=-\int_b^a fdx\]
상세 설명

적분 방향을 반대로 하면 부호가 바뀐다.

예시
\[\int_1^0x dx=-\frac12\]

96같은 상하한

\[\int_a^a f(x)dx=0\]
상세 설명

구간 길이가 0이므로 누적 변화량도 0이다.

예시
\[\int_2^2(x^2+1)dx=0\]

97정적분 선형성

\[\int_a^b(\alpha f+\beta g)dx=\alpha\int_a^bf dx+\beta\int_a^bg dx\]
상세 설명

부정적분과 마찬가지로 상수배와 합에 대해 선형이다.

예시
\[\int_0^1(2x+3)dx=2\int_0^1x dx+3\int_0^1dx=4\]

98홀함수 대칭

\[\int_{-a}^{a}f(x)dx=0\quad(f(-x)=-f(x))\]
상세 설명

원점대칭인 홀함수는 좌우 구간의 부호 있는 넓이가 서로 상쇄된다.

예시
\[\int_{-2}^{2}x^3dx=0\]

99짝함수 대칭

\[\int_{-a}^{a}f(x)dx=2\int_0^a f(x)dx\quad(f(-x)=f(x))\]
상세 설명

y축 대칭인 짝함수는 좌우 적분값이 같으므로 절반 구간의 두 배로 계산한다.

예시
\[\int_{-1}^{1}x^2dx=2\int_0^1x^2dx=\frac23\]

100누적적분의 미분

\[\frac d{dx}\int_a^x f(t)dt=f(x)\]
상세 설명

상한이 x인 누적 넓이 함수의 순간변화율은 바로 현재 위치의 함수값이다. 미적분 기본정리의 미분형이다.

예시
\[\frac d{dx}\int_0^x t^2dt=x^2\]
